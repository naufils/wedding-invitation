# Evermint — Design System

## 3.1 Philosophy
Elegant, editorial, restrained. Premium print stationery translated into motion — not "wedding website template" look. Generous whitespace, confident type, motion serves story not decorates.

## 3.2 Typography
- Display/headline: high-contrast serif — Cormorant Garamond or Playfair Display (Google Fonts, free)
- Body: clean sans — Inter or DM Sans (Google Fonts, free)
- Names/accent (optional): 2-3 curated script fonts, not open list — keeps output curated not chaotic

## 3.3 Color System
- Warm neutral base (ivory/cream bg, charcoal/deep-brown text) — avoid pure white/black
- 4-6 curated accent palette presets ("Royal Gold," "Blush Rose," "Emerald & Ivory," "Terracotta") vs open picker Phase 1 — nudges good result
- Custom override available, not default path

## 3.4 Motion Principles
- Purposeful, never decorative-for-own-sake — every anim reveals info or builds anticipation
- Staggered reveals over simultaneous — presented not dumped
- Eased curves everywhere (ease-out entrances, ease-in-out transitions) via GSAP/Framer presets — never linear
- Restraint after envelope-open — that's the one big wow; rest subtle so long scroll not exhausting

## 3.5 Component Inventory (Phase 1 template)
1. Envelope/Seal hero (3D)
2. Hero names + date reveal
3. Story section (text+image, scroll-fade)
4. Event timeline (vertical stepper, one card/event)
5. Venue card (embedded map + directions CTA)
6. Countdown widget
7. RSVP form
8. Gallery (masonry grid, lightbox)
9. Guest upload widget
10. Footer/contact/FAQ accordion

## 3.6 Responsive Rules
Mobile-first, 375px baseline (most links open from WhatsApp on-device). Desktop = secondary "showcase" mode, not primary target.
